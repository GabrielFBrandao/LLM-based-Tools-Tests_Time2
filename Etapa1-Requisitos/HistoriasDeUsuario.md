# Histórias de Usuário

## Módulo de Gestão de Quartos

### Hóspede
1. **HU-001**: Como hóspede, eu quero visualizar a lista de quartos disponíveis, para escolher aquele que melhor atende às minhas necessidades.
2. **HU-002**: Como hóspede, eu quero ver os detalhes completos de um quarto (fotos, comodidades, preço), para tomar uma decisão de reserva informada.

### Recepcionista
3. **HU-003**: Como recepcionista, eu quero cadastrar um novo quarto no sistema, para disponibilizá-lo para reservas.
4. **HU-004**: Como recepcionista, eu quero atualizar o status de um quarto (disponível/ocupado/em manutenção/em limpeza), para manter o sistema atualizado.
5. **HU-005**: Como recepcionista, eu quero adicionar/remover camas de um quarto, para configurar corretamente a capacidade de hospedagem.
6. **HU-006**: Como recepcionista, eu quero visualizar o histórico de manutenções de um quarto, para acompanhar problemas recorrentes.

### Gerente
7. **HU-007**: Como gerente, eu quero gerar relatórios de ocupação dos quartos, para analisar o desempenho do hotel.

## Módulo de Gestão de Hóspedes

### Hóspede
8. **HU-008**: Como hóspede, eu quero me cadastrar no sistema, para realizar reservas de forma mais ágil.
9. **HU-009**: Como hóspede, eu quero atualizar meus dados cadastrais, para mantê-los sempre atualizados.






### Recepcionista
10. **HU-010**: Como recepcionista, eu quero cadastrar um novo hóspede, para realizar uma reserva em seu nome.
11. **HU-011**: Como recepcionista, eu quero buscar um hóspede por nome ou CPF, para localizar rapidamente seus dados.
12. **HU-012**: Como recepcionista, eu quero visualizar o histórico de estadias de um hóspede, para oferecer um atendimento personalizado.

### Gerente
13. **HU-013**: Como gerente, eu quero gerar relatórios de fidelidade de hóspedes, para criar estratégias de retenção.

## Módulo de Gestão de Reservas

### Hóspede
14. **HU-014**: Como hóspede, eu quero verificar a disponibilidade de quartos em um período, para planejar minha estadia.
15. **HU-015**: Como hóspede, eu quero realizar uma reserva online, para garantir meu quarto com antecedência.
16. **HU-016**: Como hóspede, eu quero receber um e-mail de confirmação da minha reserva, para ter comprovante da mesma.
17. **HU-017**: Como hóspede, eu quero cancelar uma reserva, caso necessário.

### Recepcionista
18. **HU-018**: Como recepcionista, eu quero registrar o check-in de um hóspede, para iniciar sua estadia.
19. **HU-019**: Como recepcionista, eu quero registrar o check-out de um hóspede, para encerrar sua estadia.
20. **HU-020**: Como recepcionista, eu quero visualizar todas as reservas do dia, para organizar o trabalho da equipe.
21. **HU-021**: Como recepcionista, eu quero prorrogar uma estadia, caso o hóspede deseje ficar mais tempo.

### Gerente
22. **HU-022**: Como gerente, eu quero visualizar a taxa de ocupação do hotel, para tomar decisões estratégicas.
23. **HU-023**: Como gerente, eu quero gerar relatórios de faturamento, para análise financeira.

## Módulo de Relatórios

### Gerente
24. **HU-024**: Como gerente, eu quero exportar relatórios em formato Excel, para análise detalhada.
25. **HU-025**: Como gerente, eu quero visualizar o faturamento por período, para acompanhar o desempenho financeiro.
26. **HU-026**: Como gerente, eu quero identificar os períodos de baixa ocupação, para criar promoções.




## Módulo de Autenticação e Perfis

### Todos os usuários
27. **HU-027**: Como usuário, eu quero fazer login no sistema, para acessar minhas funcionalidades.
28. **HU-028**: Como usuário, eu quero redefinir minha senha, caso eu a esqueça.

### Administrador
29. **HU-029**: Como administrador, eu quero gerenciar os perfis de acesso dos usuários, para controlar as permissões do sistema.
30. **HU-030**: Como administrador, eu quero visualizar logs de acesso ao sistema, para auditoria de segurança.

## Critérios de Aceitação Gerais
- O sistema deve validar todos os campos obrigatórios
- Deve ser exibida mensagem clara em caso de erros
- A interface deve ser responsiva e acessível
- O tempo de resposta deve ser inferior a 2 segundos
- Dados sensíveis devem ser criptografados
- O sistema deve estar disponível em português do Brasil

Estas histórias de usuário cobrem os principais fluxos do sistema e podem ser priorizadas de acordo com a metodologia MoSCoW previamente definida.
