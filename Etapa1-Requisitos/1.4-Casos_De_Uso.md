## Módulo: Gestão de Quartos

### UC01 - Cadastrar Quarto
* **Ator Principal:** Recepcionista
* **Descrição:** Permite ao recepcionista cadastrar um novo quarto no sistema com todas as suas características e comodidades.
* **Pré-condições:** Recepcionista autenticado e com acesso ao módulo.
* **Pós-condições:** Quarto cadastrado com status "Livre" e visível na listagem.

**Fluxo Principal:**
1. O recepcionista acessa o módulo de Gestão de Quartos.
2. O recepcionista clica em "Novo Quarto".
3. O sistema exibe o formulário de cadastro.
4. O recepcionista preenche os campos obrigatórios (Número, Capacidade, Tipo, Preço).
5. O recepcionista marca as comodidades (Frigobar, Café, Ar, TV).
6. O recepcionista adiciona os tipos de cama na seção "Camas".
7. O recepcionista clica em "Salvar".
8. O sistema valida os dados e cadastra o quarto com status "Livre".
9. O sistema exibe mensagem de confirmação.

**Fluxos Alternativos e Exceções:**
* **FA01 - Número existente:** O sistema exibe erro de duplicação e solicita novo número.
* **FA02 - Campos vazios:** O sistema exibe validação nos campos obrigatórios.
* **FE01 - Erro no sistema:** Mensagem de erro genérica e log do sistema.

### UC02 - Listar Quartos
* **Ator Principal:** Recepcionista
* **Descrição:** Exibe a lista de todos os quartos cadastrados.
* **Pós-condições:** Listagem carregada em até 2 segundos.

**Fluxo Principal:**
1. O recepcionista acessa o módulo.
2. O sistema carrega e exibe a lista com colunas (Número, Tipo, Preço, Disponibilidade).
3. O sistema exibe botão de edição para cada item.

**Fluxos Alternativos:**
* **FA01 - Nenhum quarto:** Exibe mensagem informativa e botão para cadastrar o primeiro.
* **FA02 - Filtros:** O recepcionista aplica filtros e a lista é atualizada.

### UC03 - Editar Quarto
* **Ator Principal:** Recepcionista
* **Descrição:** Permite alterar informações de um quarto existente.
* **Regras de Negócio:** Não é possível editar um quarto que está em uma reserva ativa (exceto status e comodidades).

**Fluxo Principal:**
1. O recepcionista clica no ícone de edição na listagem.
2. O sistema carrega os dados atuais.
3. O recepcionista modifica os campos e clica em "Salvar".
4. O sistema valida, atualiza e exibe confirmação.

### UC04 - Alterar Status de Disponibilidade
* **Ator Principal:** Recepcionista
* **Descrição:** Permite alterar manualmente o status (Livre, Ocupado, Manutenção, Limpeza).

**Fluxo Principal:**
1. Na edição do quarto, o recepcionista seleciona novo status.
2. O sistema salva e atualiza a listagem.

**Fluxo Alternativo:**
* **FA01 - Quarto com reserva:** Se tentar alterar quarto com reserva ativa, o sistema emite aviso e pede confirmação.

## Módulo: Gestão de Hóspedes

### UC05 - Cadastrar Hóspede
* **Ator Principal:** Recepcionista
* **Descrição:** Cadastro de novos clientes.
* **Regras de Negócio:** CPF e Email devem ser únicos e válidos.

**Fluxo Principal:**
1. O recepcionista clica em "Novo Hóspede".
2. Preenche Nome, Sobrenome, CPF e Email.
3. Clica em "Salvar".
4. O sistema valida CPF (formato e unicidade) e Email.
5. Sistema cadastra e confirma.

**Fluxos Alternativos:**
* **FA01/FA02:** CPF ou Email inválidos geram mensagem de erro.
* **FA03:** CPF já cadastrado oferece opção de visualizar cadastro existente.

### UC06 - Listar Hóspedes
* **Ator Principal:** Recepcionista
* **Descrição:** Visualização e busca de hóspedes.

**Fluxo Principal:**
1. Sistema exibe lista (Nome, Sobrenome, CPF). *Nota: Email oculto na listagem conforme regra.*
2. Recepcionista pode usar barra de busca para filtrar em tempo real.

## Módulo: Gestão de Reservas

### UC07 - Criar Reserva
* **Ator Principal:** Recepcionista
* **Descrição:** Cria reserva associando hóspede a quarto livre.
* **Regras de Negócio:** Apenas quartos "Livre" podem ser reservados. Ao reservar, status muda para "Ocupado".

**Fluxo Principal:**
1. O recepcionista clica em "Nova Reserva".
2. Sistema lista apenas quartos "Livre".
3. Recepcionista seleciona Quarto e Hóspede.
4. Clica em "Confirmar".
5. Sistema cria a reserva e **altera automaticamente** o status do quarto para "Ocupado".

**Fluxos Alternativos:**
* **FA01:** Se não houver quartos livres, sistema avisa.
* **FA02:** Opção de "Cadastrar Novo Hóspede" dentro do fluxo de reserva.

### UC08 - Listar Reservas
* **Ator Principal:** Recepcionista
* **Descrição:** Visualização das ocupações.
* **Regra de UI:** Status deve ser exibido como chip colorido.

### UC09 - Editar Reserva
* **Ator Principal:** Recepcionista
* **Descrição:** Alteração de dados da reserva.

**Fluxo Principal:**
1. Edição da reserva.
2. Se o quarto for alterado:
    * Sistema libera o quarto antigo (Status -> Livre).
    * Sistema ocupa o novo quarto (Status -> Ocupado).

### UC10 - Cancelar Reserva
* **Ator Principal:** Recepcionista
* **Descrição:** Cancelamento e liberação de quarto.

**Fluxo Principal:**
1. Recepcionista solicita cancelamento.
2. Sistema pede confirmação.
3. Sistema cancela a reserva e **libera o quarto** (Status -> Livre).
